The primary purpose of this project was to improve my mechanical design skills. I did this through the exercise of desigining a model v8 engine that can be used to teach students how the Otto Cycle works in a real-world application. 

This web-page will document my design process and highlight important iterations during both design and manufacturing. 

I started this project by designing a connecting rod for my engine.
